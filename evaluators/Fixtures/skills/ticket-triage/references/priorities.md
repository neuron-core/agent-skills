# Support priorities

| Priority | Criteria |
| --- | --- |
| P1 | Service unavailable to all users, or ongoing data loss. |
| P2 | Essential functionality blocked for some users, with no workaround. |
| P3 | A workaround exists, or the affected functionality is secondary. |
| P4 | Information request or proposed improvement. |

A customer's requested urgency does not determine the priority by itself.
