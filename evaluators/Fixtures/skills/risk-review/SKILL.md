# Risk review

Review the proposed plan before implementation.

Identify the assumptions that would cause the plan to fail if they proved
false. Consider data loss, compatibility, service availability, and recovery.

For each significant risk, explain:
- What could go wrong.
- How the team would detect it.
- What would reduce its likelihood or impact.

Finish with the decisions that must be resolved before work begins.
If no plan has been provided, ask the user to describe it.
